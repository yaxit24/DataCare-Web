This is an independent source inventory and conditional expected fixture, not executable writer acceptance. It refines the frozen Round13 c27 contract and mandatory stock erratum without changing either. No runtime source, tests, database, browser, compiler or active plan was changed or run. Static scripts only read source statements and author the accompanying evidence.

## 1. Two newly exposed reachability decisions

**Literal untagged N has a BAR parent on this saved Save path.** Saved-open copies TAG_NO directly into c2 (`TR_SALE_RTN.cs:10369`). The BAR_DETL Save test is `Val(c9)+Val(c12)+Val(c38)!=0 AND c2!=''`, not `c2!='N'` (`13901`). P1 with pieces1, weight10, net110 and N therefore enters the parent path, with 74 ordered assignments, and adds it at14229. The first numeric event Other1 still qualifies (sum122 rather than121). BAR_DATA independently qualifies when totalMRP is nonzero or totalPCS+totalNWT+totalOTHER is nonzero (`13072`); its twelve fields are written at13080–13124.

The current row replay rejects any BAR_DETL/BAR_IDTL (`saleReturnIncomingReplay.ts:201`), and saved metadata likewise contains BAR parents (`savedSaleReturn.ts:296–309`). Thus the frozen proposal's inherited preview eligibility plus absent BAR parent is not the complete source-shaped N Save. A new profile must either admit and validate the exact harmless N companion separately, or explicitly document a limited web edit that preserves an already absent companion despite desktop creation. This analysis does not choose the latter or silently enable either. Existing preview contracts remain unchanged.

**USER_UPDATE=N is also a current admission boundary.** Desktop Save assigns N at12912; saved-open loads it into UsUPdate at10182. Save12285–12323 uses Y as an override and otherwise checks ordinary UserEdit for an edit. Current saved metadata makes N a refusal (`savedSaleReturn.ts:284`), inherited by replay. A source-shaped header therefore needs a separately reviewed saved-write admission rather than casting its current false capability to true. Fresh authenticated form Update authority remains mandatory; source override semantics are not client authority. No existing guard is removed here.

These findings do not block the independent row mapper, which always returns canCommit:false. They do block claims that the current positive preview fixture alone proves a reachable source-complete write fixture.

## 4. Post-replay and guard requirements

Run the entire accepted ordered c27 journal from trusted hydration; same-value is still an event. Compare the full source projection, bill and all effect predicates after replay. A no-op requires no persisted-value or membership change anywhere, not merely equal editor text. Preserving NULL/scale/metadata means no DML on an actual no-effect commit.

In addition to amount precision and immutable identity checks, require stable source row inclusion and the intended positive-credit/zero-received state. Under the completed plain P1 branch:

- Other=-110 produces ordinary bill0, failing the normal Save amount guard.
- Other=-120 gives net-10 and row condition weight10 + net-10=0, omitting the incoming row.
- Other=-200 switches bill to received90.
- **Other=-11 gives positive net99 but BAR_DATA condition pieces1 + weight10 + Other-11=0 while BAR_DETL remains eligible.** Positive bill alone therefore does not prove companion membership stable.

These are independent source-branch candidates, not executed expectations from incomplete P1. The first preservation-based writer must refuse these unsupported transitions or separately own and test their complete consequences.

Save's cash guard can depend on existing AcCash even when new received cash is zero; source12149–12171 requires a qualified limit/helper or proven zero configured limit. CO_SET owns CASH_LIMIT, EMP_CODE_MANDATORY and TRAD_FINE (MS_OPNCOMP690/710/713); CO_SET_NEW owns COUNTER_STK (952). Company/year opening and lock dates, defaulter state, fresh update permission, employee/counter and account existence are independent from displayed closing. Special fine branches may be proven inert for metal amount100 where their SQL requires ITM_AMT=0, but edition E audit remains potentially active and cannot be guessed away. The named ordinary Save guard and first-write profile must be explicit about any vendor-dependent admission.
