# Exact mathematical saved Return header Float storage qualification

Pure internal prerequisite only; never enables Save, authorizes identity or proves complete effect ownership. The three scoped targets are SL_DATA.RTN_NET_AMT, RTN_TOT_AMT and RTN_BILL_OS, each Prisma Float (schema5708/5709/5714). The Round13 next-write contract section7 requires a named representability policy before any new persistence. Existing source projection is a mathematical decimal profile, not measured Windows Double/Format equivalence.

Input: exactly those three own enumerable string data properties in a plain/null-prototype object. Signed plain decimal text, optional surrounding ordinary spaces, <=128 characters, no controls/exponents/prefixes, <=36 significant digits, <=18 decimal places after insignificant trailing zeros, abs<1e36. No user object accessors invoked and no Number conversion. Canonical text normalizes plus/zeros/-0 while preserving exact decimal value.

Ready only when every exact decimal rational is exactly finite IEEE754 binary64: remove all denominator powers of5, reduce powers of2, require <=53 significant binary bits, minimum exponent >=-1074 and highest set-bit exponent<=1023. This is deliberately narrower than nearest-double rounding: decimal0.1 refuses. The required calculation/persistence profile must explicitly accept this boundary; it is not general desktop floating-point parity. Unchanged imported Float fields should remain raw and need not be normalized.

Result is detached frozen values and original text, version/profile, canCommit:false. Failure has recoverable field-specific diagnostic and no candidate values; a strict-invalid envelope has no retained raw. Whole valid envelope is retained for numeric/storage refusal. No row/header replay, SQL, Number conversion, journal effects, clocks, permissions or token claims.

Literal expected cases below were authored before the implementation. Binary rational facts are exact arithmetic; no expected outcome is generated by executing the proposed qualifier. Both positive/negative0.1/2^53 adjacent/large powers/tiny dyadic cases are included. Future DB adapter must independently assert actual casts/storage roundtrips plus complete business-state atomicity before writing.
