# Pure incoming save mapping, before implementation

Export `projectSaleReturnIncomingSave(input: unknown)` and constants `SALE_RETURN_INCOMING_SAVE_VERSION='primary-incoming-save-map-v1'`, `SALE_RETURN_INCOMING_SAVE_PROFILE='saved-one-primary-untagged-c27-map-decimal-pg-v1'` from a new `saleReturnIncomingSaveProjection.ts` only. No active source, index or existing test changes.

The exact own-data input is `{rowIdentity, ordinal, raw, visible}`. Identity is an opaque64 lowercase hex token retained without claiming to authenticate it. Ordinal must be1 for this first saved-row profile. Raw is a detached plain string/NULL record, including every supplied unowned field. Visible has exactly63 numeric-string source-column keys0–70 excluding caches45/46/47/48/49/58/66/67; values are strings. No journal, policy, computed authority, master hash or SQL is accepted. The caller must separately establish trusted hydration/replay, one-row document membership and a c27-only journal. This function cannot infer those facts from a supplied map.

Every output has version/profile, `canCommit:false`, detached raw when safely recoverable, diagnostics and fixed external requirements. A ready output means only this mapping subprofile qualified. It includes58 distinct grid-owned sourceFieldValues, differences, source branch observations and candidatePatch. A structurally readable but unsupported row may retain its complete mapped values for inspection; candidatePatch is null on any refusal. Missing/malformed projection has sourceFieldValues null. No partial patch is released.

Source ownership is TR_SALE_RTN:14307–14584. The58 fields include Val numeric conversions and exact text cells; TAG_NO uses c2 or N for exactly blank, DATA_TYPE uses c70 or A for exactly blank. RATE_TYPE is c44, IT_TYPE c43, TAG_TYPE c54; c53/c55/c57 and display41/42 are not independent saved assignments. VCH_TIME/MAIN_USER/EMP_CODE at14557–14565 and the earlier scope/header assignments14260–14303 are contextual, excluded from this grid map and always retained raw. This is not a complete SQL row.

Visible Val numbers allow ASCII spaces, sign and plain decimal forms; blank means0. Refuse controls, Unicode whitespace, exponents, suffixes, NULL/missing cells, nonfinite values, more than36 significant digits or18 decimal places or absolute value at least1e36. Use a private Decimal precision100 clone, no Number roundtrip. Canonical numeric output removes formatting without changing raw. Each of OTH_AMT/TOT_AMT/NET_AMT must be exactly representable in PostgreSQL numeric(18,2), with no rounding or truncation; candidatePatch contains only mathematically changed members, formatted with exactly2 decimals. A numerically equal raw string is retained physically, including its original scale/sign text. An empty patch is only a row-map no-change observation, not a document/effect no-op.

Require existing P/I row, raw SR_NO='1', exact stable item/tag/instance/old/tag serial mapping, TAG_NO=N, positive nonzero existing instance and stable canonical A/B/C row DATA_TYPE (not session mode). Preserve unchanged Float-backed identities; never qualify a new Float assignment. Reject source omission at14252 (blank item or c12+c38=0), a row renumber, zero-instance allocation14482–14497, identity disagreement, nonpositive resulting row net, and nonzero row tax. The zero/negative checks only contain obvious unsupported row states; final bill, whole-unit zero, received direction and source Save guards still require separate final-state validation. No row/bill calculation occurs here.

All other mapped numeric fields must be present non-NULL plain decimals and mathematically equal to saved raw. This deliberately narrower subprofile refuses loaded precision loss or incidental recalculation of an unowned number; it never normalizes that field. Unowned text differences are explicitly reported as `unowned-text-preserved`; known display fallbacks such as NULL ITM_REMARK remain NULL. Stable identity/type fields additionally refuse disagreement. Numeric equality with different raw spelling is `numeric-text-preserved`; changed owned fields are `candidate-numeric-change`. A NULL mapped numeric refuses this subprofile while the original NULL remains observable.

Boundary limits: ordinary or null-prototype own enumerable data records only, no arrays/accessors/symbols/custom prototypes/extra envelope keys. Raw at most1024 fields, key length128, each string at most65536 and combined text at most262144; visible strings at most4096 and combined at most65536. Detached output remains bounded; failed raw recovery returns null rather than evaluating a getter or fabricating an empty row. No input is frozen or mutated.

Mandatory unresolved requirements on every result: fresh Update/session/document/config/master/guard authority; actual server-owned ordered c27 replay and complete poststate admission; complete effect ownership including BAR, stock, ledger, Rojmel, tax, outstanding and remarks; Float header/storage qualification; one Serializable atomic writer. TAG_NO=N is nonblank in desktop and can enter BAR save paths, so an untagged row never proves BAR absence. MAIN_STOCK identity is SR_NO2/ISR_NO=incoming SR_NO, not nonexistent SR_REC_ISU. Unknown closing remains unavailable and is neither a granted save permission nor an invented universal prohibition.

The fixture is authored from source assignments and literal poststate examples before the new module exists. It tests mapping only, not that those visible maps were calculated or admitted by a real desktop/server. Full effect fixtures remain a separate workstream.
