# Browser response observation correction — not yet rerun

The first actual browser run failed after the login check. Its real same-scope selection upstream hold succeeded and delivered HTTP200; the next ordinary same-scope reopen called `await response.text()` as an assertion-message argument only after the click had returned. The product intentionally performs full navigation on successful selection. Chromium had discarded the old response resource, producing `Network.getResponseBody: No resource with given identifier found`. The same late-read pattern occurred in later login/me/retry observations, so both journey modules now use the same event-time body observer.

The new helper registers an ordinary Playwright response listener before the triggering UI action. On the matching response event it starts response.body() synchronously, without first waiting for click/goto/dialog completion. It retains actual response bytes/status/headers/request metadata for later assertions. Subsequent text/json calls read those captured bytes; they do not query a resource belonging to an old document. Failed or non-JSON real reads still fail the journey. The helper adds no route, navigation interception, API request or fabricated response content. Existing intercepted cases continue reading their actual route.fetch APIResponse unchanged.

The correction changes only response observation timing. All original12 and additive2 check strings, assertions and five declared real-response transport injections remain. Full navigation, exact epoch/receipt/DOM/database comparisons and the product implementation are unchanged. Frozen staging and first failed artifacts are preserved. Only these new corrected copies and helper require integration; the optional runner itself does not change.

Prettier formatted the staged files. No browser, DB, compiler or runtime tests were run by this correction task. The root's new browser run is required before any pass claim. This is a harness timing correction, not evidence that the first run passed or that the product was defective.
