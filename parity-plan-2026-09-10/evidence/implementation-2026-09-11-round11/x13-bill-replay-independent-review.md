## Concrete corrections found during review

1. **Unicode editor whitespace:** the reused v1 parser and frozen row kernel could accept U+2028/NBSP and trim it into0 before the aggregate ASCII guard saw it. Root added a v2-only printable-ASCII input guard. The old core/v1 semantics remain unchanged.
2. **Terminal field-ID separator:** JavaScript `$` could accept canonical field text followed by U+2028, misclassifying an unknown ID as a known-but-unsupported field. Root extended the v2 field-ID guard too. Authenticated vectors now require400 for both field and editor cases; no event executes.
3. **Preview activation acknowledgment:** the new parent ownership helper could refuse an activation while a child still opened/requested because the callback returned void. Both child panels now obtain a boolean acknowledgment before token/open/busy/GET. Parent validation uses synchronously updated selection/draft/operation refs. Own close can release even if eligibility changed; stale or other-owner close cannot release the current owner. The corrected source was reread, with the67th UI case covering rejected claim and valid close. Real browser verification remains root-owned.
