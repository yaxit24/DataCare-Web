## Required dataset boundary

The primary `TR_SALE_RTN.cs` has **two different grids and parent datasets**. `MSG` is the outgoing exchange/sale leg: its grid starts at5868, saved read is `SL_DETL` at10236, and `dataRow3` writes that table at14800–15027. `MSG_PR` is the incoming returned-item leg: its grid starts at3563, saved read is `SL_DETL_RTN` at10353, `RsPrDetl` is queried at13030, `dataRow5` is created at13042, `val3=MSG_PR` at14248, and its write is14319–14569. The print adapter separately projects outgoing `SL_DETL` and incoming `SL_DETL_RTN` into issue/receipt report rows at15194–15196.

**Do not add all 33 fields to SL_DETL_RTN or copy the ordinary Sales writer wholesale.** The list mixes genuine incoming edits, hidden copied identities, header fields, outgoing-only values/constants, duplicate labels, and alternate modes. `TR_SALE_RTN_UAE.cs` explicitly chooses `SL_DETL_RTN` for its non-Purchase-Return branch at7942–7957 and writes `RATE_WITH` at8857, which the current return Prisma model lacks. That proves an alternate schema contract needing investigation; it does not justify enabling UAE formulas for the primary form.

`apps/web/app/(app)/txn/sale-return/page.tsx:75–123` exposes extended descriptors;334–352 builds payload cells using dynamic `Object.fromEntries`. That expression is not fully supported by the bounded scanner. Final result is708 checked/33 without confirmed write paths, retained in `dead-cells-strict.json` and `dead-cells-strict.txt`. Unsupported serialization syntax is still a failed diagnostic, not a reason to mark a field live.

Independently of that limitation, `salesReturn.ts:354–401` has a fixed incoming writer mapping that omits these keys; the original-source and saved-return reads at599–633 and693–698 expose only subsets. It already maps `otherWt` to ITM_OTH_WT, so another `lessWt` control cannot be safely guessed into the same cell. Current header origin uses originalNo/originalBook/current selected year at407–410; the primary source has distinct original year/location/book fields. The current write/reversal table list at643–654 includes SL_DETL_RTN and financial/stock rows, but no outgoing SL_DETL/SL_IDTL or generated BAR_DATA/BAR_DETL/BAR_IDTL leg. This document does not assert that every possible caller/variant was exhaustively traced.
