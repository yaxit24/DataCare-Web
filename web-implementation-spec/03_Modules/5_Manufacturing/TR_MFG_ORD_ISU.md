## Purpose
Issue a design into the shop **against an open sales order** rather than an ad-hoc lot. The grid pulls
open order lines and, on save, marks them consumed and starts the working lot. Book `DESIGN ISU`
(`CO_BOOK 301`, `IR_TYPE='D'`, `LAST='X'`, `NEXT='W'`). _(src: `Mfg_Module.cs#L85` MFG_MAST seed.)_

## Deltas vs TR_MFG_ISU_REC
- **Order pick:** grid sources open order lines `SL_ORD_DETL WHERE DESIGN_ISU='N' AND TAG_STK_LESS<>'Y'`.
- **Order link columns on `MFG_DETL`:** `ORD_NO, ORD_YRCD, ORD_DBCD, ORD_AC_CODE, ORD_DESIGN, ORD_SRNO`
  (grid cols 70–77 in the `TR_MFG_KR_ISU_REC` map).
- **On save:** after writing the `MFG_*` trio (with `ORD_*` set), `UPDATE SL_ORD_DETL SET DESIGN_ISU='Y'`
  for each consumed order line. _(src: `RP_ALL.cs#L10933` `UPDATE SL_ORD_DETL SET DESIGN_ISU='Y'`.)_
- **Stones OUT:** `Ac_Stock.Mfg_DM_Stk_Less` posts a `MAIN_STOCK` `-` for issued stones (the
  `MsMfgWithOrder` branch keys `SR_NO>100`). Working tag generated by `ItmTagGen()`.
- `MFG_ISU_REC` projected as an **issue** (`ITM_SIGN='-'`, `IR_TYPE='D'`).

## Footprint
`MFG_DATA`/`MFG_DETL`/`MFG_IDTL` → `MFG_ISU_REC` (issue) → `MAIN_STOCK` (stones less) → `UPDATE
SL_ORD_DETL.DESIGN_ISU='Y'`; `DELETE_DATA` on reverse (and `DESIGN_ISU='N'` rollback to re-open the order).

## Build note / risks
Requires the order+lot schema additions (`MFG_ISU_REC.ITM_LOT/REC_*`) and the `Mfg_With_Order` book
chain (300–318) seeded. Cross-module dependency on Sales orders (`SL_ORD_*`). Reverse must re-open the
consumed order line (`DESIGN_ISU='N'`). Pairs with [`TR_MFG_ORD_REC.md`](TR_MFG_ORD_REC.md).
