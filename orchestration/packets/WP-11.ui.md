## Goal

Build the dedicated Sales Report screen at `web/apps/web/app/(app)/reports/sales-report/`, split exactly like the
GST Report page (`page.tsx` under about 300 lines, a `useSalesReport.ts` hook, a `SalesReportGrid.tsx` component,
`types.ts`). It calls the existing API (`GET /reports/sales-report?…`, `/export.csv`, `/export.xlsx` in
`routes/rpAllReport.ts`); read the query parameter names from `rpAll/filters.ts` and the result shape from
`rpAll/types.ts`. Do not change the API.

## Facts you need

- Screen content (inventory `docs/parity/rpall-sales-inventory.md` §2-§3): the shared selectors in desktop order,
  From and To defaulting to today, the location lock, Employ and Select Book visible, State hidden in Lite, the 13
  Lite buttons with their desktop captions (Sales Report, Sales Reg, Item Wise, Sales Bill, Employ Sales,
  Cash/Bank Bill, Wh Sales, Wh Summ, Emp WhSales, Counter Sales, Sale With Order, Group Sales, Labour Work). Buttons
  whose mode the API does not serve yet (§5: Sales Bill, Cash/Bank Bill, Wh Sales, Wh Summ, Emp WhSales, Counter
  Sales, Labour Work) are shown but disabled with a title that says "Not available yet"; check what the browser
  module expects for them and follow it.
- Grid: bands and totals as the API returns them (do not recompute totals on the page). Zoom to the voucher: open
  the Sales Invoice screen for the row's voucher, as the GST Report drill-down does.
- Keys: Enter walks the selectors, F1 / Enter on an empty lookup opens help (`lib/lookupEnter.ts`), Esc closes the
  screen even with no focused control (`lib/screenEscape.ts`). No request on each keystroke: one read per Run.
- Point the Reports navigation item "Sales Report" in `web/apps/web/lib/nav.ts` at `/reports/sales-report`, and
  classify the route as edition `L` in `docs/handbook/web-route-editions.json`; regenerate
  `web/packages/core/src/editionTable.ts` with `node scripts/generate-edition-table.mjs` (from web/).
- Never grow `reports/[report]/page.tsx`. A file may not pass 1,500 lines.

Make the locked module `salesReport.mjs` pass. Do not edit it; if a case contradicts the inventory or the desktop,
quote both and report PARTIAL. If the API lacks a field the screen needs, list it under "Questions for the
supervisor" and finish the rest.
