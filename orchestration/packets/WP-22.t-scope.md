## Goal

Write one database test file for the cases about who may create a year, for whom, and what happens when it is created twice, at the same
time, or fails. All but one pass today. `concurrency.same-year-two-requests` fails today and passes after packet `WP-22.impl-alt` adds the lock.

## Facts you need

- Database tests cannot run here (no Docker); they run on CI. Local gates: `pnpm typecheck`, `pnpm typecheck:tests` from `web/`.
  Report every test as "written, not run".
- Copy setup and cleanup from `web/apps/api/test/masterSaveFidelity.db.test.ts:1-60` (229 lines) and the calling style
  (`createYear(runtime, scope, {...})`, `YearValidationError`) from `:169-229`. `year.ts` is 172 lines. `txn.ts` is 8,142 lines: you do not touch it.
- The web route `POST /years` uses the `create` guard (`txn.ts:6357`); `guard` answers `403 {error:'forbidden', action}` (`txn.ts:927`).
  To test a user without the right, find how an existing route test builds the app and a limited user (search `web/apps/api/test/` for `forbidden`
  and `app.inject`). If no helper builds a user without a right, write `MISSING: limited-user helper` in the report and test only that the route
  policy requires `create` for `POST /years` (`web/apps/api/src/modules/rbac/routePolicy.ts:918`); do not invent a helper.
- Case texts and expected values: `cases.md:79-107` (`field.year-code-route`, `field.closing-date-route`), `cases.md:122-130`
  (blank code refused), `cases.md:517-600` (rights, scope, concurrency, retry, year-row rollback).
- Concurrency: use two Prisma clients (two connections), start both `createYear` calls with `Promise.allSettled`, assert exactly one fulfilled,
  one rejected with a `YearValidationError` matching `/already exists/`, one `YEAR_MAST` row, and the clone ran once (`AC_GROUP` count equals the
  template's). Repeat the pair 5 times with different year codes (new company code each time) so a lucky ordering does not pass.
- `rollback.year-row-failure-no-copy`: with the owner client add a trigger on `YEAR_MAST` that raises for `CO_CODE='04'`; drop it in `finally`.
