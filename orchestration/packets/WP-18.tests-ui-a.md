## Goal

Write the first half of the browser module for the HuId report: the seed helper shared by all browser cases, and the case entries for defaults (T01),
filters (T02), totals (T03) and invalid input (T06). Packets `tests-ui-b` and `tests-ui` build on your two files.

## Facts you need

- Model: `web/apps/web/test/features/modules/accountLedger.mjs` (read it whole). Its `C(...)` helper builds a case entry `{id, group, kind, source, applicable, requiredEvidence, run}`,
  `notApplicable(...)` builds N/A entries, `exec(ctx, sql, ...)` seeds with `ctx.owner` and `ctx.tenantId`, and `cleanCase(ctx)` removes what the case owns.
  Copy these helpers into your files; do not import them from `accountLedger.mjs`.
- Case text, steps and expected values: `cases.md`. Test data: `cases.md:896-937` (16 tags and 3 sentinels). Route: `/reports/huid`.
- Page contract (the page does not exist yet; write the selectors from this list and say so in the file header): buttons by accessible name `Stock Tag`, `In Tag`, `Out Tag`, `Print`, `Excel`, `Cancel`, `Exit`;
  labelled inputs `From`, `To`, `Search`, `Item Type` (select: Gold, Silver), `Product`, `Group`, `Tag No`, `HuId Type` (select: All, With HuId, Without HuId), `Ac Code`; the grid is `role=grid` with one `role=row` per tag
  and a totals row with `data-testid="huid-totals"`; cells have `data-col="<key>"` where key is a row key from `design.md` section 1 (`tagNo`, `grwt`, ...).
- `huidSeed.mjs` exports `seedHuid(ctx)`, `cleanHuid(ctx)` and `HUID_TAGS` (tag and the views it belongs to). `seedHuid` inserts the seed with `ctx.owner.$executeRawUnsafe` (items, product, group,
  accounts, `BAR_DETL`, `MAIN_STOCK`, plus the sentinels); `cleanHuid` deletes exactly those rows by tag and code. Use the tag numbers `TG-001` and so on from the table, so cleanup is exact.
- `huidReportFilters.mjs` exports `filterCases` (an array of case entries). Use `group` values `T01`, `T02`, `T03`, `T06`, `kind` `read-only`, and `source` equal to the case's desktop citation text.
