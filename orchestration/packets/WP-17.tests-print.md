## Goal

Test the print of the Cash Bank report: `GET /reports/cash-bank/print` returns the `AcLedger` layout as html. The tests are written before the route exists and fail with 404 until `WP-17.print` lands.

## Facts you need

- Use the app setup, users and seed functions of `web/apps/api/test/cashBankReport.db.test.ts` and `web/apps/api/test/support/cashBankSeed.ts` (written by `WP-17.tests-db`; import them, do not copy).
- Query: the same as the screen route (`fromDate`, `toDate`, `acCode`, optional `bookCode`). Response: `200`, `text/html`. Without the print right: `403` with the text `You Have No Print Rights.....`. The same refusal applies to `/export.pdf`, `/export.xlsx` and `/export.csv`.
- Cases (each an `it` named with the case id; expected values from `cases.md` lines 395 to 462, with the template or desktop line quoted in a comment):
  - print.template-regions: the html contains the headings `Debit Rs`, `Credit Rs`, `Ac Name`, `Balance`, and the captions `Opening Balance :`, `Transaction Total :`, `Closing Balance :`.
  - print.title-parameter: contains `Cash and Bank Report From 01/11/2026 To 30/11/2026` for seed A.
  - print.opening-amount-unfiltered: seed A, no book: the opening value is `-7500.00`.
  - print.totals-and-closing: Transaction Total Dr 13500.00 and Cr 2500.00; Closing Balance 11000.00 with side `Dr`. Compare numbers after removing thousands separators, because the print's number format is not decided.
  - A rights case: the user without the print right gets 403 on `/print` and on the three export routes; the user with it gets 200 on `/print`.
- Do not assert the blocked cases (print.opening-with-book, print.balance-zero-side, print.balance-column-format, scope.year-sentinel). Write a one-line comment naming each with its reason.
- Use the same `enabled ? describe : describe.skip` pattern as the other database tests (`RUN_DB_INTEGRITY_TESTS === '1'`).

## Steps

1. Read `cashBankReport.db.test.ts` lines 1 to 80 for the setup.
2. Write the file; run `pnpm typecheck:tests` and `pnpm lint` from `web/`.

## Out of scope

The print code, other test files, blocked cases, `baseline.json`.
