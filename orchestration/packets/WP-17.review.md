## Goal

Review everything this work package changed, as a reader who did not write it. You do not edit application code or tests. Your output is `orchestration/work/WP-17/review.md`: a list of findings, each with a file and line, what is wrong, the case or desktop line that shows it, and a severity (`money or tenant`, `behaviour`, `style`).

## Facts you need

- The diff: run `git diff --stat origin/main...HEAD` and `git diff origin/main...HEAD -- web/apps/api web/apps/web` (read by file; do not print everything at once). The design is the contract; the desktop is the authority (`study.md` quotes it).
- Check in this order, because the first ones can silently give a wrong ledger:
  1. **Tenant, company and location scope.** Every query in `cashBankReport.ts` and the help list states `CO_CODE` and `LC_CODE`, runs inside `withTxBudget` with the tenant id, and uses bound parameters only. Search the new files for `$queryRawUnsafe` with a template string that holds a request value (a finding if any).
  2. **Sign and boundaries.** Opening uses `<` From, detail `>= From` and `<= To`; `SUM(CR - DR)` below zero is Dr; totals include the opening; the side is empty at zero; paise arithmetic (no float sums).
  3. **Grouping and names.** Group key `BOOK_NAME, CO_BOOK, VCH_NO, VCH_DATE, LEDR_KEY, LD_CODE`; party name from `SL_DATA` for SALES, `PR_DATA` for PURCHASE, the counter-party otherwise.
  4. **Rights.** Every export and the print call the print guard first; the 403 text is `You Have No Print Rights.....`; `routePolicy.ts` lists each new route under `Reports/Cash / Bank Book` and the print routes in `PRINT_ROUTES`; the `app.ts` exemption is only for `/reports/cash-bank`.
  5. **Print and screen agree.** The print opening comes from the resolver, not a second query.
  6. **Screen.** No arithmetic in the page; no `SendKeys`-style simulated keys; codes upper-cased only in the two code boxes; no Delete button; no refill on a date change; link keys not in cells.
  7. **Size and standards.** `txn.ts` grew by two lines only; no file over 600 lines in the new files; nothing added to `reports/[report]/page.tsx`.
  8. **Tests.** Each case id of `design.md` section 6 has a test; no `skip`, `only` or `baseline.json` change; expected values are literals from `cases.md`.
- Quote the code you cite (file, line, the text). A finding without a quote is not a finding.
