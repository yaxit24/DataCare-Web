## Goal

Write the second half of the browser module: lookup, drill-down, scope and rights, concurrency, history, output and keyboard case entries.

## Facts you need

- Read `huidReportFilters.mjs` and `huidSeed.mjs` (written by `tests-ui-a`). Copy its helpers (`C`, `exec`, selectors) and import `seedHuid`, `cleanHuid`, `HUID_TAGS` from `./huidSeed.mjs`.
  The page contract (accessible names, `data-col`, `huid-totals`) is in `tests-ui-a`'s brief and `design.md` section 3. Export an array `outputCases`.
- Case text and expected values: the `cases.md` ranges in the context list. Users: the users in `../fixtures/catalogue.mjs` (`USERS`). For the rights cases create the user and its `USER_SET` row
  the way `accountLedger.mjs` does for its rights cases (view right only; print right off).
- Downloads: for the Excel, CSV and PDF cases follow the download handling in `accountLedger.mjs` (its T16 cases) and assert on the file contents, not only on the click.
- The refusal message for a user without the print right is exactly `You Have No Print Rights.....` (`RP_HUID.cs:1361`), shown in the page, grid unchanged.
- The drill-down case expects only that a double click on a row does something the desktop does (opens the source voucher); read its Expected and assert exactly that, no more.
