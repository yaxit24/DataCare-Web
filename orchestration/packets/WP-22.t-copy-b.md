## Goal

Write database tests for the first-year copy of the tables in group B. Seven tables are copied whole (their tests pass today and must keep
passing); four have a row selection and a narrower column list (their tests fail until `WP-22.impl-copy`).

## What to cover

1. One `it` per case id above, named with the case id. Whole-table cases assert the new company's row count equals the template's.
2. Row-selection cases assert the exact code set (`DM` copied and `ZZ`/`AB`/`002` not).
3. Column cases assert the dropped columns are NULL for the new company while the kept columns equal the template's.
4. Tenant B: one `it` that a second tenant's company `01` with the same codes is neither read nor changed.
5. Default `cloneCompany` (no `selection`): one `it` asserting it still copies all rows of `EMP_MAST` (`001` and `002`).
