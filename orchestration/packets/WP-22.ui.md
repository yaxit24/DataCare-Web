## Goal

Make the existing page `masters/year-create/page.tsx` (238 lines) behave like the desktop `MS_YEAR` form for entry, keys and date messages, and show the start-month field for an
alternate-year company. Change nothing else: the list of years and the Carry Forward panel stay as they are.

## Facts you need

- The browser suite and a dev server cannot run here. Local gates: `pnpm typecheck`, `pnpm lint`, `pnpm format:check` from `web/`. Say in the report that the screen was not seen in a browser.
- Page today: year code (line 87), start month (92), opening and closing `type="date"` inputs (106, 115), preview from `fiscalYearDates` (145-147), **Create Year** button (140), list (39), Carry Forward panel (195-227).
- The test ids to put on the elements: `year-code`, `year-month`, `year-opening`, `year-closing`, `year-save`, `year-cancel`, `year-exit`, `year-message`, `year-list` (`data-testid`). The browser module `yearCreate.mjs` uses them.
- Behaviour (desktop; study Keyboard and Rules):
  1. On open and on Cancel: code `Y-(Y+1)` / `(Y-1)-Y`, month `04`, opening `01/04/<first year>`, closing `31/03/<second year>` from today's date (`MS_YEAR.cs:1037 {{Strings.Mid(Conversions.ToString(DateAndTime.Today), 7, 4)}}`);
     for an alternate-year company use `alternateYearDefaults` from `@datacare/core` and show the month field (`GET /years/context` returns `{ alterYear }`; the field is hidden otherwise,
     `MS_YEAR.cs:887 {{((Control)tMonth).Visible = true;}}`). Focus on the code (`MS_YEAR.cs:1054 {{((Control)tYearCode).Focus();}}`).
  2. Dates are text in `dd/mm/yyyy` (mask `00/00/0000`, `MS_YEAR.cs:714 {{mOpDate.Mask = "00/00/0000";}}`); convert to ISO only when posting. Use `formatDesktopDate` from core for display.
  3. Enter in the code moves to the opening date. Enter in the opening date validates it: invalid day shows `Date Not Valid...`, invalid month shows `Month Not Valid...`
     (`DC_Main.cs:1644 {{Date Not Valid...}}`, `DC_Main.cs:1664 {{Month Not Valid...}}`), clears the field to `__/__/____` and keeps focus; valid moves to the closing date and, for an alternate company, copies
     the month from the opening date (`MS_YEAR.cs:1111 {{tMonth.Text = Strings.Mid(mOpDate.Text, 4, 2);}}`). Enter in the closing date validates the same way, then focus goes to `year-save`.
  4. Esc closes the screen (go back in history), `MS_YEAR.cs:955 {{if ((int)e.KeyCode == 27)}}`.
  5. Typed letters are upper-case; the apostrophe is ignored (`MS_YEAR.cs:947 {{e.Handled = true;}}`).
  6. Buttons: `&Save` (Alt+S), `&Cancel` (Alt+C), `E&xit` (Alt+X). Remove the **Create Year** caption. No Delete, no Print.
  7. Keep the API message texts on refusal (`year 2026-2027 already exists`, `closing date ... must be after opening date ...`, the `forbidden` text): show the server's text in `year-message`.
- `year-code` keeps `maxLength={9}` (the 15-character code is not built: design section 9). Keep `errorText` as is.
- Keep every file under 600 lines; if `page.tsx` would pass 450, move the form fields into `yearFields.tsx` in the same folder.
