## Goal

Make a new company's first year copy the desktop's baseline set (design section 2) instead of everything, without breaking the accounts,
book slots and tax rows the voucher writers resolve (design section 3). This code runs for every company the service provisions and a
wrong row set is silent: follow the design table exactly and add the integrity check.

## Facts you need

- You may edit `companyClone.ts` (531 lines now; keep it under 700) and `year.ts` (172 lines; ONE line: pass the option). You cannot edit tests.
  The tests you must satisfy are the three files named in `context`; read them first. They cannot be run here (no Docker); CI runs them.
  Local gates: `pnpm typecheck`, `pnpm lint`, `pnpm format:check` from `web/`.
- Today: `COMPANY_CLONE_TABLES` (`companyClone.ts:23-456`), 20 entries incl. `BOOK_DETL` twice (lines 238 and 284) and the web-only `AC_MAST_SRNO`
  (:218) and `BANK_RECONCILE` (:227); `cloneCompanyTx` (:475-520) does one `INSERT ... SELECT` per table, skipping a table that already has rows.
- Add to `CloneCompanyOptions`: `selection?: 'all' | 'baseline'` (default `'all'`: **do not change what `cloneCompany` and every existing caller do**).
  Add to `CompanyCloneTable` three optional fields: `baselineColumns` (subset of `columns`), `baselineWhere` (a **static string constant** over
  the source alias `s`), `baselineConstants` (e.g. `{ DATA_TRFR: "'N'" }`, static), and `baseline?: false` (table not copied in baseline mode).
  Never put a request value into the SQL text; bind only tenant, company and location as parameters.

  write the numeric test as a `CASE` because PostgreSQL does not order `AND` operands and `CAST` of `CASH` raises an error.
- Baseline location (design rule L): `00` if the template has a `LOCT_MAST` row `00`, else the template's lowest `LC_CODE`; compute once per call, bind as a parameter,
  use it for AC_MAST, BOOK_DATA, BOOK_DETL, LOCT_MAST.

- `assertBaselineUsableTx(tx, tenantId, coCode)`: runs at the end of a baseline call, same transaction; throws `Error` with a message naming the table and code
  when (a) `LOCT_MAST` has no row, (b) a `BOOK_DATA` book has no `BOOK_DETL` row or the reverse, (c) a non-empty `BOOK_DETL.AC_CODE`, `TAX_MAST.TAX_AC`,

  `createYear` runs inside one transaction, so the throw rolls back the year row and the copy.
