## Goal

Write the unit and database tests for every `unit` and `database` case in `orchestration/work/WP-14/cases.md`
(Report → Order Report, desktop RP_ALL with caption "Order Report"), before any implementation. Copy the structure,
seeding and helpers of `rpAllSales.db.test.ts` and `rpAllSales.test.ts` (the Sales branch on the same engine). Put
pure SQL/shape tests in `rpAllOrder.test.ts` and route tests in `rpAllOrder.db.test.ts`. Expected values are computed
in the test from the seeded rows with the desktop formula quoted in the case, never read back from the app.

## Done when

- Every unit/database case id of cases.md appears in a test name or comment; blocked cases are listed in `red.md`.
- `red.md` records each test, the command and the failing lines (or PARTIAL if Docker was unavailable).
- `pnpm typecheck:tests` passes.
