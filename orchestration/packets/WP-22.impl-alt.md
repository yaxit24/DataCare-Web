## Goal

Three small changes in the code path of `createYear`: (1) the alternate-year branch of the desktop; (2) a transaction lock so two simultaneous creates of the same year give
one year and one clone; (3) a read-only route so the page knows whether the company is an alternate-year company.

## Facts you need

- Cannot run here: database tests (no Docker). The core unit tests can run: use the fourth gate. Say which database tests (`yearCreate.alt.db.test.ts`, `yearCreate.scope.db.test.ts`) you expect to pass.
- Sizes: `fiscalYear.ts` 67 lines, `year.ts` 172 (after `impl-copy`: 172 plus one line), `routePolicy.ts` 1,297, `txn.ts` 8,142 and **may gain at most two lines**.
- Rules (design section 5): `alternateYearDefaults({year, month})` returns code `Y-(Y+1)` for months 4-12 and `(Y-1)-Y` for months 1-3, month = current month padded to 2,
  opening `01/MM/Y` where Y is the **first four characters of the code for April-December and the later year (the second half of the code) for January-March**, closing one year later, first day of the month.
  Vectors are in the test `fiscalYearAlt.test.ts`; the tests are the specification. `alternateYearKey(code, month)` = first four characters of the code + padded month.
  Citations: `MS_YEAR.cs:1189 {{dataRow["CO_YEAR"] = Strings.Mid(tYearCode.Text, 1, 4) + tMonth.Text;}}`, `MS_YEAR.cs:1111 {{tMonth.Text = Strings.Mid(mOpDate.Text, 4, 2);}}`.
  Export both from `web/packages/core/src/index.ts`.
- `createYear` (`year.ts:63-110`): read the flag **inside the transaction**: `SELECT "ALTER_YEAR" FROM "CO_MAST" WHERE tenant_id=$1 AND "CO_CODE"=$2 LIMIT 1`. When `'Y'`:
  month = `yearMonth` input, else the opening date's month, else current month; `CO_YEAR` = `alternateYearKey`; `OLD_METHOD 'N'`; default closing = opening + 1 year (not minus one day);
  duplicate check on the stored key; return `{ coYear, coYearKey, opDate, clDate }`. When not `'Y'`: unchanged behaviour. The request body can never set the flag or `OLD_METHOD` on a standard company
  (today `oldMethod` is accepted from the body: for a standard company keep `'Y'` regardless; test `year-create.alt` item "body alterYear ignored").
  The 9-character limit (`year.ts:77`) stays.
- Lock: first statement of the transaction `SELECT pg_advisory_xact_lock(hashtext($1))` with the text `year-create:<tenantId>:<coCode>`; copy the pattern of `addressMaster.ts:128`. Place it before the duplicate probe.
- Route: new file `routes/yearContext.ts` exporting a function that registers `GET /years/context` returning `{ alterYear: boolean }` for the session's company, read with the same scope helper
  `txn.ts:6352-6355` uses (`readScope(req)`; follow `routes/taxMaster.ts` for how a route file receives `app`, `auth` and `prisma`). Register it with at most two lines in `txn.ts`
  (import + call). Add `'GET /years/context'` to the `Masters/Year Create` list at `routePolicy.ts:918`. If `routePolicy.test.ts` or `test/route-coverage.mjs` need an update, say so in the report; you cannot edit tests.
