## Goal

Track O (plan §6) proves the web's arithmetic against the desktop's own code compiled on .NET Framework 4.8. Family 1
(sale line) is done: `web/scripts/desktop-oracle/sales-line/Oracle.cs` copies `TR_SALE.CommPassTotal`
(`TR_SALE.cs:9524-11891`) verbatim with stand-ins for the grid. Family 2 is **tax and HSN rounding, the
CGST/SGST/IGST split and the bill round-off (`Fnv`)**. This packet writes the study a later packet will use to build
`web/scripts/desktop-oracle/tax-hsn/Oracle.cs`, so it must give exact line ranges, not summaries.

## What to cover (sections of `orchestration/work/WP-41/family2-study.md`)

1. `## Methods`: the desktop methods that compute the bill's tax and round-off on the Sales screen, starting from
   `TR_SALE.MSG_TOT_FILL` (`TR_SALE.cs:9078`) and `TR_SALE.BILL_TOTAL` (`TR_SALE.cs:19189`), and every method they
   call for tax (HSN rate lookup, local vs interstate, half-tax rounding) down to `DC_Main.Fnv`
   (`DC_Main.cs:2088-2102`). For each: name, line range, what it reads and writes (grid columns, text boxes,
   `DC_Main` settings).
2. `## Inputs`: every value the methods read that a vector must supply (grid cells by column number, settings such as
   rounding flags, state codes, HSN rates), with the line that reads it.
3. `## Outputs`: every value written that the oracle must report (taxable amount, each tax, round-off, bill total).
4. `## Stand-ins`: what must be faked as family 1 does (grid, text boxes, message boxes, database lookups), and
   anything that cannot be faked.
5. `## Web counterparts`: the `@datacare/core` functions that compute the same values (search `saleAmount.ts`,
   `money.ts`, `roundingPolicy.ts` and grep `cgst`/`hsn` under `web/packages/core/src`), one line each.
6. `## Vector plan`: the boundary cases (`.5` half-tax, zero, negative returns, every tax rate in the seed,
   local and interstate, round-off on/off).
7. `## Open questions`.

## Done when

- The study has the seven sections and every method has an exact line range with a quote.
- The citation check passes with at least 30 quoted citations.
