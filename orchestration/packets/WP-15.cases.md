## Goal

Turn the study of Report → Tag Stock (`orchestration/work/WP-15/study.md`, 14 numbered gaps) into the frozen case
list. The next sessions write tests from your list and are measured against it, so each case needs concrete steps,
seeded movements, and an expected value worked out from the desktop rule.

## Facts you need: the supervisor's decisions on the study's questions

The owner's standing rule is "the desktop first": the operator sees and does what the desktop does, and the web adds
only what an internet-hosted, multi-user service needs to be safe and correct.

1. **Scope.** The Lite menu Report → Tag Stock: the six Tag Wise modes, Tag Summ and Product Stk as the Lite dispatch
   reaches them. The detail-only and Jadtar projections (`RP_TAG.cs:3890-3976`, `:5615-7287`) are separate menus:
   list them under "Not covered".
2. **Stock state.** Use the desktop's signed-movement rule from the study exactly; for every Stock case show the
   seeded movements and the sum. Cover a cancelled tag, a sold tag, a returned sale tag and an approval-pending tag.
3. **Totals.** Totals cover every selected row. No row cap: a case seeds more rows than one page and asserts the
   totals and the CSV equal the full set (gap 7).
4. **Desktop defects, decided:**
   - In mode with a Book filter (alias defect, `RP_TAG.cs:4013`): the web applies the evidently intended book filter.
     The case expects filtering to work and states it as a deliberate difference.
   - A valid Book lookup must keep the chosen value (the desktop clears it): deliberate difference, one case.
   - Summary MRP and size come from staging columns the desktop never fills: such a case is `blocked` with that reason.
   - Company merge: not in Lite scope. Write one database case proving no row from another tenant or company appears.
   - Voucher zoom: the web opens the voucher only when the user has the Read right of the target menu (the desktop
     treats a missing right as allowed). Deliberate difference, one case.
   - The F1 TagNo repair writer and the diagnostics panel (`pnlDiff`) are not ported: a case expects them absent.
5. **Print and export.** Refused without the Print right (report addendum); one case for Print and one for CSV/Excel.
   Crystal layout fidelity beyond title, columns and totals is listed under "Not covered".
6. **Settings.** Assume the Lite defaults: no wholesale columns, no company merge. Wholesale-only columns are `N/A`.
7. **Desktop sort orders** per mode (gap 14) are cases, not notes.

## Out of scope

- Writing tests or code. The Stock Report (`RP_STOCK`).

- Every expected value is derived from a quoted desktop rule, with the arithmetic shown.
